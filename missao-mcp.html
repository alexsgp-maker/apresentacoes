O que o sistema precisa

Seis peças para falar com a IA.

A base · o sistema já deve ter
  • Porta de entrada (API)Outros programas podem fazer pedidos ao sistema. Sem isto, a IA não entra.
  • Dados organizadosEquipamentos, clientes e Folhas de Obra identificados e ligados entre si.
  • Permissões por utilizadorCada pedido tem uma pessoa por trás, com o seu nível de acesso.
A camada MCP · é preciso construir
  • Menu de funçõesA lista do que a IA pode pedir: consultar, criar, atualizar.
  • Servidor MCPMostra o menu à IA e leva os pedidos ao sistema. Faz-se uma vez.
  • Registo e confirmaçãoTudo fica registado. Ações que alteram dados pedem um OK humano.

Cuidados

Antes de ligar, três cuidados.

  • A IA pode enganar-se.Por isso, tudo o que altera dados passa por confirmação humana.
  • O que a IA lê passa pela conversa.É preciso decidir que dados se expõem, sobretudo os dos clientes.
  • Cada função é trabalho.Começar com um menu pequeno, bem testado, e crescer devagar.

O MCP não é segurança por si só. Permissões e separação de dados têm de ser desenhadas no sistema.
