O que o sistema precisa

Seis peças para falar com a IA.

A base · o sistema já deve ter
  • Porta de entrada (API)Outros programas podem fazer pedidos ao sistema.
  • Dados organizadosEquipamentos, clientes e Folhas de Obra ligados entre si.
  • Permissões por utilizadorCada pedido tem uma pessoa por trás.
A camada MCP · é preciso construir
  • Menu de funçõesA lista do que a IA pode pedir.
  • Servidor MCPMostra o menu à IA e leva os pedidos ao sistema.
  • Registo e confirmaçãoTudo fica registado. Ações que alteram dados pedem um OK humano.

Cuidados

Antes de ligar, três cuidados.

  • A IA pode enganar-se.Tudo o que altera dados passa por confirmação humana.
  • O que a IA lê passa pela conversa.Decida que dados se expõem, sobretudo os dos clientes.
  • Cada função é trabalho.Comece com um menu pequeno e bem testado.

O MCP não é segurança por si só. Permissões e separação de dados têm de ser desenhadas no sistema.
